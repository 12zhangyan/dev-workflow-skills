# Conversation handoff template

按当前证据裁剪；没有信息增益的字段省略。

```markdown
# <任务名> 移交

## 目标与边界
- 原始目标：...
- 当前授权 / 禁止事项：...
- 当前状态：Completed / InProgress / PartiallyComplete / NeedsConfirmation / Blocked / NotStarted

## 已完成与当前工作区
- 已证实动作或产物：...
- changed / VCS owner 与状态：...
- 验证：<命令、退出码、关键结果；或未运行及原因>

## 证据边界
- 已证实：...
- 对话声明、当前未复核：...
- 推断：...
- 待确认 / blocker：...

## 接手入口
- 先核验：<最能裁决当前动作的文件或命令>
- 可立即推进：<一个动作，或互不覆盖的并行动作及各自完成判据>
- 在途工作：<所有者/句柄、范围、状态、等待条件；没有则省略>
- 需要时再扩展：<触发条件与证据方向>

## 最小证据索引
- <路径或命令> — <为什么需要读；证明什么>

## 可复制提示
请先阅读 <handoff 路径>，核验“最小证据索引”的首要材料，然后推进当前可执行动作；独立切片可并行，已有在途工作不要重复派发。保留其中的授权、敏感信息、数据库和 VCS 边界；若当前状态与移交冲突，以当前可复核证据为准并报告差异。
```

移交文档本身是证据索引，不复制完整方案、源码、diff、日志或测试输出。`Blocked` 必须给最小补充项；推荐方案不是授权。
