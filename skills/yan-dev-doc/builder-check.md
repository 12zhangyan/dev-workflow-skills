# 实现者试读

只在 yan-dev-doc 自查后、方案含两个及以上切片或跨切片接口时读取。目的：交给用户前，找出实现者开工前必须问的问题。

## 执行

宿主可委派且当前任务已授权委派时，派一个只读 Agent；否则由当前 Agent 换成实现者视角自己读一遍。派发内容只有方案路径、仓库根目录和下面的要求，不附对话历史和作者的推理。

给试读者的要求：

- 以即将独立实现本方案的工程师身份阅读方案，按需查阅仓库代码；
- 列出开工前必须得到答案的问题，每条附方案位置（`S-n`、`A-n` 或章节）和不回答会怎样做错；
- 只读：不改文件、不运行测试或构建、不再委派；
- 没有问题时回复“无问题”。

## 分类处理

| 类别 | 判定 | 处理 |
|---|---|---|
| 已有答案 | 方案、仓库或对话已能回答 | 把答案补进方案对应位置 |
| 可自定 | 合理的实现者可以自行决定，且不改变交付结果 | 自行决定，在证据表标为 Agent 代决 |
| 需用户 | 答案会改变交付结果、业务口径、权限或接口 | 写入待裁决 `Q-n`，按重要性合并为一条消息交给用户 |

试读只做一轮，修改方案后不再重复。试读失败或没有返回时，在交付中说明未完成试读，不编造问题或结论。
