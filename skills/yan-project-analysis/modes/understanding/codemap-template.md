# CodeMap document template

按目标裁剪，不要求每节都存在。

```markdown
# <功能名> 代码地图

> 入口选择依据：...
> 范围与未展开边界：...
> 关键证据：...

## 概览
[请求/事件从哪里进入，经过什么关键环节，最终产生什么结果]

## 调用链
[短链用文本；分支或跨组件较多时用 Mermaid。节点使用 类名.方法名()]

## 状态与副作用
[仅记录实际存在的状态变化、事务/并发机制、DB/缓存/MQ/外部调用]

## 关键代码位置
| 位置 | 作用 | 证据说明 |
|---|---|---|

## 方案与实现对照
[仅在输入确有方案或契约时，用中性语言记录一致、偏差和未确认项；不定性为 Bug]

## 证据边界
- 已证实：...
- 假设/未确认：...
- 未展开：...
```

图、状态机、变量追踪和方案对照只在能提高理解时加入。隐含前置条件用中性事实描述，不输出风险等级、finding、修复建议或通过结论。
