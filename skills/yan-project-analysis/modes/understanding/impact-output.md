# ImpactAnalysis output

只呈现支持用户决策的信息，不复制固定空字段。

```markdown
## 结论
[一句话说明兼容性结论及证据强度]

## 契约与调用链证据
- [实际变化或与结论相关的维度]：<旧 → 新；位置>
- [入口 → 关键适配层/调用方 → 副作用或终点]

## 影响清单
| 对象 | 结论 | 原因与证据 | 需要动作 |
|---|---|---|---|
| ... | 明确受影响 / 证据显示不受影响 / 待确认 | ... | ... |

## 边界
- 未展开或不可见实现：...
- 假设/待确认：...
```

未变化维度可合并说明，不要机械展开。兼容性影响不是 Bug 定性；需要缺陷判断时交给只读 review，需要实施时交给开发方案或普通开发流程。

用自然语言明确本次是零写入影响分析；只有机器交接需要时才补 `AnalysisMode`、`WritePolicy` 或 `artifacts` 字段。

异步、流式或队列场景只在相关时补充客户端断连、重连、刷新、消息顺序、重复投递或最终一致性；每项仍需证据。
